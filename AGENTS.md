# Project Rules

- Do not reference specific CTF competition names (CompFEST, BrunnerCTF,
  etc.) in code, tests, or documentation.
- Keep examples impersonal: `demo`, `ctf.example.com`, `<event>`.
- Describe cases and lessons generically: "a kernel-pwn task",
  "a lattice-based crypto task" — no event or task names.
